# Level 4 · Selenium Grid, Scaling & Production Practices

A test framework that works for one person, running one test, locally, still has real production concerns
left to solve: running many tests in parallel, scaling across real browser instances with Selenium Grid,
handling modern Shadow DOM components, executing JavaScript directly when the WebDriver API can't reach
something, and running the whole suite inside a real CI pipeline. This level also gives Selenium a fair,
direct, evidence-based comparison against Playwright — not a reflexive "which is better," but a real look at
what actually differs.

By the end of this level you'll have run a real local Selenium Grid, executed real tests in parallel, and
built a complete, production-shaped Selenium framework as this course's capstone.
