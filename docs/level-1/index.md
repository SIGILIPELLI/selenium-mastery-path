# Level 1 · WebDriver Fundamentals & Locators

Before writing a single test, you need a real browser you can drive and a reliable way to find the exact
element you want inside it. This level builds both from the ground up against a real local Flask test-target
app: setting up a real Chrome WebDriver session, every major locator strategy (ID, name, class, CSS, XPath),
and the full real range of element interaction — clicking, typing, dropdowns, checkboxes, navigation, and
reading an element's actual state.

By the end of this level you can launch a real browser, find any real element on a page, interact with it
correctly, and read back its state — and you'll have built a real, working login-flow test.
